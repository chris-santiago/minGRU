# experiments/ — file index

What each file in this folder is and where it came from. The canonical narrative of every experiment round lives in [EXPERIMENTS.md](EXPERIMENTS.md); this index is the map.

## Top-level documents

| file | purpose |
|---|---|

| [TECHNICAL_REPORT.md](TECHNICAL_REPORT.md) | Publication-style synthesis of the state-tracking variants investigation (S3/S3-hier tasks, mixer family, training protocols). Frozen results-mode prose plus dated bracketed addenda for later developments. |

## Conventions

- **Evidence strata are never mixed silently**: pinned-CPU rows (torch 2.5.1) vs L4 (torch 2.8/cu128/triton 3.4) vs A100 rows are labeled in every artifact and every EXPERIMENTS.md table.
- Numbers in EXPERIMENTS.md are transcribed from these artifacts, never from memory; artifacts are regenerated whole by their scripts, never hand-edited (the one provenance-marked exception is documented inline in `gpu_delta_probe_fused_l4.md`).
