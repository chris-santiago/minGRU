# experiments/ — file index

What each file in this folder is and where it came from. The canonical narrative of every experiment round lives in [EXPERIMENTS.md](EXPERIMENTS.md); this index is the map.

## Top-level documents

| file | purpose |
|---|---|
| [EXPERIMENTS.md](EXPERIMENTS.md) | The round-by-round evidence ledger — every experiment round (design, method, per-seed results, verdicts, artifacts) appended chronologically. The single source of truth for measured claims. |
| [TECHNICAL_REPORT.md](TECHNICAL_REPORT.md) | Publication-style synthesis of the state-tracking variants investigation (S3/S3-hier tasks, mixer family, training protocols). Frozen results-mode prose plus dated bracketed addenda for later developments. |
| [SUMMARY.md](SUMMARY.md) | Length-generalization investigation summary and handoff notes (predates the packaged repo; historical context for the loop that produced the mixer family). |
| [RELATED_WORK.md](RELATED_WORK.md) | Prior-art survey: DeltaNet/DeltaProduct lineage, fla (flash-linear-attention) incumbent kernels, chunked-WY literature. Grounds the novelty and no-incumbent-comparison disclosures. |
| [index.md](index.md) | This file. |

## Lab and probe code

| file | purpose |
|---|---|
| [hetero_lab.py](hetero_lab.py) | The S3-hier training lab: intervention arms for the `signed -> rotation` trainability problem (`hetero-loop` rounds), plus the promoted-mixer arms (`hetero-pg8`, `hetero-pd64`, `hetero-pd1024`). Emits per-seed `MINGRU_LAB_ROW` lines; `--device cuda`/`--compile` flags for GPU campaigns; `--selftest` runs the delta bridge check. |
| [variants.py](variants.py) | Experimental minGRU variants from the length-generalization loop. Lab code only — nothing here is wired into `src/mingru/`. |
| [mechanism_probes.py](mechanism_probes.py) | Mechanism verification probes: converts the loop's headline claims from inference to demonstration (weight-level evidence). |
| [repair_probes.py](repair_probes.py) | Repair round 1: inference-time projection + injection probes testing the "failure is calibration, not search" hypothesis. |
| [repair_round2.py](repair_round2.py) | Repair round 2: projection + fine-tune (b-lite) and hom-error checkpoint selection (c) on failed seeds. |
| [reversal_emulation.py](reversal_emulation.py) | Division-reversal error emulation for the chunked reversible backward — reproduces the design-phase measurement behind the no-division rule as a committed artifact. |
| [benchmark_tasks.py](benchmark_tasks.py) | Accepted-benchmark validation round: the `TaskSpec` contract (data/loss-mode/fit-eval protocol binding) plus the data generators/loader for the round's four tasks — S5 (symmetric-group word problem), MQAR (multi-query associative recall), psMNIST (permuted-pixel MNIST; synthetic stand-in loader, no torchvision/download locally), and the pendulum (irregular-timestep regression). Data synthesis only — training is `benchmark_lab.py`'s job; models are the packaged mixer registry's. |
| [benchmark_lab.py](benchmark_lab.py) | Accepted-benchmark validation round: the task-agnostic single-arm train/eval driver. Consumes `benchmark_tasks.py`'s `TaskSpec`/generators, builds one of the registered arms (`ARM_REGISTRY`: nine matrix arms — the six packaged-mixer stacks log/signed/rotation/signed-rotation/givens/delta, the two promoted hetero stacks signed-givens/signed-delta, and the classical `gru` control; plus off-matrix `PROBE_ARMS` for the S5 design-correction probe and `REF_ARMS` for the gru-large reference) via `min_gru.MinGRUStack`, trains one seed, selects a checkpoint by the task's own fit metric, evaluates its generalization protocol, and emits one `MINGRU_LAB_ROW` ledger row — mirroring `hetero_lab.py`'s `run_arm` shape. `--selftest` runs a tiny dry-run sweep of all four tasks (wiring smoke test, not evidence). |

## Conventions

- **Evidence strata are never mixed silently**: pinned-CPU rows (torch 2.5.1) vs L4 (torch 2.8/cu128/triton 3.4) vs A100 rows are labeled in every artifact and every EXPERIMENTS.md table.
- Numbers in EXPERIMENTS.md are transcribed from these artifacts, never from memory; artifacts are regenerated whole by their scripts, never hand-edited (the one provenance-marked exception is documented inline in `gpu_delta_probe_fused_l4.md`).
